# Rough edges

The kinds and the entry's format are compound-v's (`compound-v:interrogate`, references/rough-edges.md). On this machine, each rough edge is one comment on the private log [Applesauce-Labs/forge#8](https://github.com/Applesauce-Labs/forge/issues/8), which holds the full definitions: `mise exec -- gh issue comment 8 -R Applesauce-Labs/forge --body-file <file>`. Log it when it happens, not at the end of the session.

Also log, as `more-discussion`, a Sugarhouse item the user marks "not useful to ask", with its reason. If you can't post, as in a read-only sandbox, put the line in your final message for the caller to post.
